# 地图选点、一键导航与静态密码登录 — 功能说明与配置指南

> 适用版本：2026-10-18 之后主干。涉及端：移动端 H5/微信小程序、PC 后台管理端、后端服务。

## 一、功能总览

| 功能 | 端 | 入口 |
|---|---|---|
| 地图选点（拖拽中心锚点 + 关键词搜索，自动回填经纬度与结构化地址） | 移动端客户提报需求单、PC 后台直建工单/派单弹窗 | 表单内「地图选点」按钮 |
| 位置提交双模式（全量 / 纯经纬度） | 移动端需求提报表单 | 「位置信息提交模式」切换 |
| 一键导航 | 移动端司机首页/工单列表工单卡 | 工单卡「一键导航」按钮 |
| 静态密码登录（开关后台可控、实时生效） | 移动端登录页 | 「密码登录」切换标签；开关在后台「系统配置」 |
| 日期快捷选项（今天/明天/后天） | PC 后台直建工单/需求单转工单弹窗 | 时间字段旁三个按钮 |
| 创建账号带初始密码 | PC 后台员工/客户新增表单 | 勾选「同时创建登录账号」后填写 |

## 二、高德地图 API Key 的配置位置与配置方法（重点）

本系统所有高德能力的 Key 均存于系统配置表，**在后台界面配置即可生效，无需改代码或重新构建**。

### 2.1 申请 Key（高德开放平台）

1. 注册/登录 [高德开放平台](https://lbs.amap.com/) → 控制台 → 应用管理 → 创建新应用
2. 为该应用添加两个 Key：
   - **Key A（Web 服务）**：服务平台选「Web 服务」——用于后端代理的逆地理编码（坐标→地址）与关键词搜索
   - **Key B（Web 端 JSAPI）**：服务平台选「Web 端(JS API)」——用于 H5 与后台管理端的地图渲染；创建时需配置安全密钥（jscode）
3. 小程序端地图渲染使用微信原生 map 组件，**不需要**高德渲染 Key；逆地理/搜索统一走后端代理，小程序后台只需把自家接口域名加入 request 合法域名，无需配置高德域名

### 2.2 在系统中配置（后台 → 系统配置）

| 配置键 | 填什么 | 谁使用 |
|---|---|---|
| `map.amap.web_key` | Key A（Web 服务 Key） | 后端代理（不下发前端，不可见） |
| `map.amap.jsapi_key` | Key B（JSAPI Key） | H5 地图渲染 + 后台地图渲染（随 public-config 下发前端） |
| `map.amap.security_jscode` | Key B 对应的安全密钥 jscode | 同上（仅 H5/后台渲染需要） |
| `map.mock` | `true`=模拟模式（无 Key 联调，返回固定模拟数据）；`false`=真实调用高德 | 联调开关 |

操作路径：PC 后台 → 系统配置 → 找到 `map.*` 配置项 → 行内编辑保存，**保存即生效**（后端配置缓存写穿透，无需重启）。

### 2.3 各端行为矩阵

| 场景 | web_key 有 | jsapi_key 有 | 行为 |
|---|---|---|---|
| 联调（默认） | 否 | 否 | map.mock=true：选点/搜索返回模拟数据；后台与 H5 地图画布降级为手动坐标+反查；小程序原生 map 正常可用（仅反查为模拟地址） |
| 生产 | 是 | 是 | 全功能：小程序原生地图+真实逆地理/搜索；H5/后台高德地图渲染 |
| 仅配了 web_key | 是 | 否 | 后端代理真实可用；后台/H5 地图降级（提示补配 jsapi_key）；小程序全功能 |

## 三、地图选点功能说明

### 3.1 移动端（客户提报需求单）

- **拖拽选点**：地图中心固定十字锚点，拖动地图使锚点对准目标位置（野外无地址场景推荐用法）
- **搜索选点**：输入关键词（防抖 300ms）调用后端搜索代理，下拉选择 POI 后地图自动居中
- **确认回填**：点「确认选点」自动调逆地理代理，回填经度、纬度、结构化详细地址（省市区街道+格式化地址），用户无需手输任何位置信息
- **双端实现**：小程序=微信原生 map 组件；H5=高德 JS API 2.0（动态注入，含安全密钥）；H5 无 Key 时降级为手动坐标+反查
- **提交双模式**（表单内切换）：
  - 模式一·全量：提交经纬度 + 完整地址文本（默认）
  - 模式二·纯经纬度：仅提交坐标，地址字段自动生成占位文本「自定义点位（经度…，纬度…）」以满足后端必填校验

### 3.2 后台管理端（直建工单 / 需求单转工单）

- 「地图选点」按钮打开选点弹窗：点击地图取点、拖拽地图取中心锚点、关键词搜索三种方式
- 确认后自动回填表单的经度/纬度/地址三个输入框；保留手动输入能力（Key 未配置不阻塞建单）

### 3.3 后端代理接口（供前端调用，需登录态）

| 接口 | 说明 |
|---|---|
| `GET /api/v1/system/amap/regeo?lng=&lat=` | 逆地理：坐标 → 结构化地址（formattedAddress/province/city/district/township/adcode） |
| `GET /api/v1/system/amap/place/text?keywords=&lng=&lat=` | 关键词搜索提示（最多 10 条，含坐标） |

坐标非法返回 20007；真实调用高德失败返回 50004（高德服务异常），前端提示并保留手动输入路径。

## 四、一键导航功能说明（司机端）

- 工单卡「位置」行的「一键导航」按钮（工单有坐标时显示）
- 小程序：调起微信内置地图页（uni.openLocation），页面自带「到这去」进入原生导航
- H5：跳转高德 URI API（`uri.amap.com/navigation`），手机端自动唤起高德 App 或网页导航
- 无坐标工单提示「该工单无位置坐标」

## 五、静态密码登录说明

- 登录方式：手机号 + 密码，与验证码登录并行；入口在移动端登录页「密码登录」标签
- **实时生效开关**：后台 → 系统配置 → `auth.password_login_enabled`（渲染为开关）。关闭后小程序/H5 端密码登录立即返回 30015「管理员已关闭密码登录」（无需重启服务，无发布）；**PC 后台与大屏不受该开关控制**（避免锁死管理员）
- 密码存储：BCrypt 不可逆加密（spring-security-crypto），数据库仅存哈希，禁止明文
- 设置密码途径：① 后台新增员工/客户时勾选「同时创建登录账号」并填初始密码；② 后台「账号与权限」→ 对应用户「重置密码」
- 未设密码的账号走密码登录返回 10010（账号或密码错误）

## 六、联调测试记录

- 自动化：`bash scripts/e2e-smoke.sh`（需后端 7777 运行），本期新增用例后 **29/29 通过**，覆盖：逆地理/搜索代理（模拟模式）、选点地址回填、创建司机带初始密码、司机密码登录、开关关闭实时拒绝（30015）、开关恢复实时生效
- 三端一致性：后台选点与移动端选点均消费同一代理接口与同一份 public-config 下发配置，坐标与地址数据口径一致（后端统一落 biz_work_order/biz_demand_order 的 longitude/latitude/address 字段）
- 手工用例建议（微信开发者工具，需真实 appid）：
  1. 客户提报 → 地图选点拖拽锚点 → 确认 → 检查表单三字段回填 → 提交后后台需求单详情核对经纬度/地址一致
  2. 模式二提交 → 后台核对地址为占位文本、经纬度正确
  3. 司机端工单卡 → 一键导航 → 微信地图页显示目的地并可进入导航
  4. 后台关闭密码开关 → 小程序密码登录入口隐藏且接口拒绝；开启后恢复
- 小程序真机注意：manifest.json 的 mp-weixin.appid 需替换为真实 appid；小程序后台 request 合法域名加入生产 API 域名

## 七、常见问题

- **搜索/反查返回「模拟」字样**：`map.mock=true` 或 web_key 未配置，按 §2.2 配置真实 Key 后置 false
- **后台/H5 地图空白**：jsapi_key 未配置或安全密钥不匹配；高德控制台需将生产域名加入 JSAPI Key 的域名白名单
- **小程序地图白屏**：确认使用真实 appid 与已配置的 request 合法域名
- **关闭开关后管理员无法登录后台？** 不会：开关仅对 X-Client=h5/mp 生效，后台（admin）与大屏（screen）始终可用账号密码登录
