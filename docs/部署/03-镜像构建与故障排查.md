# 镜像构建与启动故障排查

## 1. `failed to resolve reference ... crane-backend` 403

典型报错：

```text
Error response from daemon: unknown: failed to resolve reference
"docker.io/library/crane-backend:v2026.10.19-205516-48b987e":
unexpected status from HEAD request to
`https://mirror.ccs.tencentyun.com/v2/library/crane-backend/...`: 403 Forbidden
```

### 原因

`crane-backend` 是服务器本地构建的私有镜像，不存在于 Docker Hub。

出现该报错说明：

1. 本地没有对应版本的 `crane-backend` 镜像；
2. compose 在镜像缺失时尝试从 Docker Hub 拉取；
3. 腾讯云镜像加速器对不存在的 `library/crane-backend` 返回 403。

### 旧发布包（205516 及更早）的额外问题

旧包中：

- jar 位于 `backend/crane-backend.jar`
- `Dockerfile.runtime` 却要求 `backend/target/crane-backend.jar`

因此 `build-server-image.sh` 会失败，镜像没有生成。

### 立即修复（不重新上传）

```bash
cd /crane/backend
mkdir -p target
mv crane-backend.jar target/crane-backend.jar 2>/dev/null || true

cd /crane/deploy
bash build-server-image.sh
docker images | grep crane-backend
docker compose up -d
docker compose ps
```

只有当 `docker images` 能看到 `crane-backend:<APP_VERSION>` 或 `crane-backend:latest` 时，启动才会成功。

### 新发布包（210017 及之后）

发布包已修正为 `backend/target/crane-backend.jar`，并支持 compose 自动构建：

```bash
cd /crane/deploy
docker compose up -d --build
docker compose ps
```

`docker-compose.yml` 已配置：

```yaml
crane-app:
  image: crane-backend:${APP_VERSION:-latest}
  pull_policy: never
  build:
    context: ../backend
    dockerfile: Dockerfile.runtime
```

## 2. 基础镜像拉取失败

首次构建需要拉取：

```bash
docker pull eclipse-temurin:17-jre
```

如果拉取失败，检查 `/etc/docker/daemon.json`：

```json
{
  "registry-mirrors": ["https://mirror.ccs.tencentyun.com", "https://docker.1ms.run"]
}
```

```bash
systemctl restart docker
```

> 重启 Docker 会重启同机其他容器，建议在维护窗口执行。

## 3. `.env` 密码格式错误

常见错误是把注释拼到了密码值同一行：

```ini
MYSQL_PASSWORD=xxxxxxxx# 安全密钥（必须修改...）
```

检查长度：

```bash
cd /crane/deploy
awk -F= '/^MYSQL_PASSWORD=/{print "MYSQL_PASSWORD length=" length($2)}' .env
awk -F= '/^CRANE_JWT_SECRET=/{print "JWT length=" length($2)}' .env
```

期望：

- `MYSQL_PASSWORD`：32 位左右（不含 `#`、空格、引号）
- `CRANE_JWT_SECRET`：64 位左右

正确格式必须换行：

```ini
MYSQL_PASSWORD=<密码>

# 安全密钥
CRANE_JWT_SECRET=<密钥>
```

如果 MySQL 已经用错误密码初始化且没有业务数据，可重置：

```bash
cd /crane/deploy
docker compose down -v
# 修正 .env
docker compose up -d --build
```

## 4. 启动后 502 Bad Gateway

```bash
docker compose ps
docker logs crane-app --tail 200
docker exec crane-nginx nginx -t
```

检查：

- `crane-app` 是否运行；
- 后端是否监听 7777；
- MySQL 是否 healthy；
- Nginx 是否代理到 `http://crane-app:7777`（不是 8080）。

cd /crane/deploy
